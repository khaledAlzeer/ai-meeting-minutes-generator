# Assets

Place static assets used by the application here, for example:

- `logo.png` — displayed in the app header if present (see
  `src/config/settings.py` → `PathConfig.logo_path`). If this file is
  absent, the header simply renders without a logo image.
- Screenshots referenced from the main `README.md`.

This folder is safe to commit; it should not contain secrets or generated
output (see `outputs/`, which is git-ignored).
